---
name: Focused navigation
description: Navigation hierarchy for the architectural drawing register
---

The app should feel like one focused Drawing Library workspace rather than a collection of equally weighted modules. Show every distinct post-merge destination directly in the sidebar without restoring overlapping legacy pages.

**Why:** The user wants all features immediately accessible, while separate pages for closely related drawing and people tasks created unnecessary navigation fragmentation.

**How to apply:** Keep Overview, Drawing Workspace, Projects, Assignments, Review & deadlines, My Feed, Team Chat, Notifications, Checklists, Contacts, Issue register, Standards, Reports, Activity history, Recycle bin, People, Settings, and Admin visible as appropriate. Keep Drawing Workspace as the entry point for library, review, deadlines, and files; keep People admin-only; do not add legacy Team Directory, Portal Users, Review Queue, Deadlines, or Files links back to the sidebar.
